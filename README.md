# AutoPlug
This repository is meant to be a simple inventory of some click-to-run scripts for Windows Diagnostics. Aimed at IT related employees who need to gather intel on the device in specific categories. This repository also contains certain click-to-install or click-to-download software applications. 

These applications are mostly open-source or published under a public-usage license. Besides that, most if not all click-to-download software options are automated to bring you (the user) to the official page of the software where more can be read and/or seen.
